# React Implementation Projects

This repository consists of small, highly focused projects built to master React.js core implementation concepts, state management, and modern styling solutions.

## 🚀 Projects Index

### 1. BgChanger
A background color switching application built to explore dynamic state changes and real-time UI updates.
* **Core Concepts**: React `useState` hook, inline style mappings, dynamic event handlers.
* **Tech Stack**: React (Vite), Tailwind CSS v4.

---
## 🛠️ Global Tech Stack Focus
* **Framework**: React.js (Vite)
* **Styling**: Tailwind CSS v4 (using the modern CSS-first `@theme` structure)
* **State Management**: React Hooks
